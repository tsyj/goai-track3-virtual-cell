# 方法

## 1. 数据结构：先把实验设计还原出来

元数据里没有说明设计，但可以从 `Yeast_cell_plate` × `protein_well` 还原：

- **一块板 = 一个测量上下文**。144 块板，每块板内 `data_source`、`Medium`、
  `Temperature`、`pert_time`、`instrument` 全部唯一。
- **WAYB 板**：6 菌株 × 16 孔条件（Water、DMSO 两个对照 + 13 个化合物 + 一个 EDTA 重复），
  菌株按列成对排布。
- **WAYC 板**：2 菌株 × 48 孔条件（Water、DMSO、QC + 45 个化合物）。
- WAYB / WAYB_rep1 / WAYB_rep2 是**同一套设计的三次独立重复**——这是全数据集里
  唯一能直接测出测量噪声的地方。
- **`pert_id` 不是化合物身份**：`#2` 在 WAYB 是 EDTA、在 WAYC 是 DMSO。
  一律用 `perturbation_no_concentration` 作为化合物身份。

关键结构性事实：**每一块含测试样本的板上都同时有训练样本**。
未见菌株 CRD 在 WAYB 板上占第 1–2 列，其余 5 个菌株在第 3–12 列且标签可见。
因此板级批次效应可以在完全不接触测试标签的前提下估计出来。

## 2. 信号预算：先量清楚有多少东西可学

| 量 | 数值 | 怎么测的 |
|---|---:|---|
| 板（批次）单独解释的方差 | **88%** | 各因子单独的组间平方和 |
| 化合物单独解释的方差 | 33% | 同上 |
| 菌株 | 23% | 同上 |
| 重复间 Δ 相关系数 | **0.136** | WAYB 三批次共 5,366 个重复对 |
| 真实扰动效应 rms | **0.146** log2 | 由上一行反解 |
| 单样本测量噪声 rms | **0.26** log2 | 同上 |
| 高效应蛋白方向一致率上限 | 0.597 | 重复对之间 |

**扰动效应比测量噪声小一倍**。这决定了后面所有的建模取舍：
能拿分的地方主要在批次结构，不在扰动模型。

> 一处需要修正的早期结论：我们最初观察到"在可加模型内部加容量（低秩、经验贝叶斯、
> 板位置、条件-单元交互）全都变差"，并据此推断"这份数据不支持更大的模型容量"。
> **这个推断把适用范围说宽了。** 换一个模型族（残差上的梯度提升）确实捞出了
> 可加模型漏掉的信号，见 §3.1。正确的说法是：**在可加族内部加容量不划算，
> 但可加族本身表达能力不够。**
> 补做了跨族验证之后（§3.2，又试了 embedding MLP、集成、跨菌株池化交互项，
> 全部不如"可加 + 残差 GBDT"），这个结论才算落在了它该在的范围内。

## 3. 模型

一个统一的可加模型，在 log2 空间上用**收缩回填**（shrunken backfitting）拟合：

```
y(i,p) = mu(p) + offset(i)
       + plate(q_i,p) + plate×strain + strain + strain×{medium,temp,time,source}   ← 批次
       + compound(d_i,p) + compound×{time,temp,medium,source,strain}               ← 扰动
```

设计要点：

1. **批次项和扰动项一起拟合，而不是先用对照孔定基线**。
   对照孔只占 1,158 / 13,412；扰动效应（0.146）远小于板效应（0.656），
   所以板上每一个孔都在为这块板的水平提供信息。
   在 val 镜像上，这一条把总分从 0.407 提到 0.457。

2. **基线是"平滑过的对照水平"，不是"照抄匹配对照孔"**。
   照抄反而更差（0.398 vs 0.406），原因见第 4 节。

3. **留出实体的项自动归零**。CRD 没有任何可见标签，
   `plate×strain`、`strain`、`compound×strain` 对它都是 0，
   等价于"按可见菌株的平均表现预测"——这是无信息时的最优估计。
   代价可测：隐藏菌株行的基线 rmse 0.544，可见菌株 0.276。

4. **收缩强度**每项一个 λ，在内层镜像上选（板项 λ=0.3 最优，比默认的 1.0 好 0.003）。
   试过按蛋白的经验贝叶斯 λ_p = σ²_p/τ²_p，**实测变差**（0.470 → 0.459），未采用。

5. **响应空间是低秩的**：化合物效应空间前 5 个主成分解释 80% 方差，秩 5 重构与
   同一化合物留出一半样本的相关系数达 0.70。直接把可加模型的化合物项做低秩截断
   没有收益；但这个性质是第二层（§3.1）能把 5,243 个输出压到 96 维的依据。

### 3.1 残差上的梯度提升（第二个模型族）

可加模型只能表达「若干一阶 / 二阶列联表之和」。更高阶的交互它写不出来。
所以在它的残差上再训一层：残差先做 PCA 降到 96 个主成分（蛋白质组残差足够低秩），
每个成分训一棵 LightGBM，特征是设计元数据（菌株 / 化合物 / 板 / 仪器 / 培养基 /
温度 / 时间 / 孔位）。

内层镜像上 **0.4359 → 0.4498**；官方 val 镜像上 **0.4711 → 0.4811**。

消融（内层镜像，96 成分）：

| 去掉什么 | 总分 | M3 |
|---|---:|---:|
| 什么都不去（完整） | 0.4498 | 0.263 |
| 去掉板 ID | 0.4456 | 0.252 |
| 去掉孔位 | 0.4454 | 0.249 |
| **去掉化合物 ID** | **0.4379** | **0.218** |
| 只留上下文（去掉化合物+孔位） | 0.4351 | 0.219 |
| 可加模型本身 | 0.4359 | 0.222 |

**驱动力是化合物 ID 特征**：去掉它，提升几乎全部消失（0.4351 ≈ 可加模型的 0.4359）。

### 3.2 又试了两个模型族，都不如它

为避免重蹈"只在一个族里做实验"的覆辙，把候选族扩到三个（内层镜像，2 折）：

| 模型 | 总分 | 结论 |
|---|---:|---|
| 可加模型 | 0.4359 | 基准 |
| **+ 残差 GBDT（96 成分，800 棵，31 叶）** | **0.4493** | ✅ 采用 |
| + 残差 GBDT，63 叶 / 127 叶 | 0.4495 / 0.4499 | 容量不是瓶颈，不值得 |
| + 残差 embedding MLP（3 seed 平均，扫了宽度/轮数/权重衰减） | 0.4363 – 0.4370 | ❌ 明显更差 |
| + GBDT 与 MLP 集成（0.75/0.5/0.25 权重） | 0.4425 – 0.4471 | ❌ 都不如纯 GBDT |
| + 化合物×上下文（跨菌株池化）交互项 | 0.4374（单独）/ 0.4484（叠 booster） | ❌ booster 已经覆盖了 |

最后一项值得说明：`scripts/23` 发现一个很朴素的估计量——「同化合物在同
培养基/温度/时间/来源下、对**可见菌株**取平均的 Δ」——在未见菌株划分上
拿 0.373，比当时的模型（0.346）还高，说明可加模型漏了这块（它只有二阶
列联表，写不出这个五阶单元）。补上这一项后可加模型确实涨了（M4 0.235 → 0.243），
**但叠在 booster 上就没有增量了**——GBDT 已经把这块交互学走了。

**三个模型族、五种加容量的方式，只有"可加 + 残差 GBDT"这一种组合有效。**

最后还试了「未见菌株划分单独换估计量」：把该划分的预测按权重 w 混向那个池化
经验估计量。结果是一条干净的取舍曲线——

| w | 0 | 0.25 | 0.5 | 0.75 | 1.0 |
|---|---:|---:|---:|---:|---:|
| FC[未见菌株]（进 M2） | 0.282 | 0.294 | 0.303 | 0.308 | **0.310** |
| M4 药物均值残差 | **0.249** | 0.248 | 0.244 | 0.237 | 0.228 |
| 总分 | 0.4493 | 0.4500 | 0.4488 | 0.4462 | 0.4425 |

最优 w=0.25 只值 +0.0007，**低于折间波动，不采用**。
但这条曲线本身是个发现，见 §4.4。

一点保留：留出化合物在训练里根本没出现过，树对未见类别只能走默认分支，
所以它给未见化合物的其实是「一批训练化合物的某个子集平均」而非该化合物的特异响应。
**我们没有完全弄清它为什么在 M3 上有效。** 一个检验是看提升在"修正口径"下
（Δ 两边都用预测值、不共享实测噪声）是否还在：总分 0.3637 → 0.3993 **还在，而且相对增幅更大**；
但其中 M3 部分几乎没动（0.187 → 0.190）。
→ **M2 / M4 上的提升是真的建模收益；M3 上那部分很可能还是指标几何造成的。**

实现上把观测掩码提到内层循环之外（掩码是固定的，`S @ Rz` 与每组计数都是常数，
而项在自己的层级内是常数，所以 `S @ (M * term)` 退化成 `counts * term`），
拟合时间从 179 s 降到 54 s。

## 4. 评测框架的审计

我们按手册重写了六个模块（`vcell/metrics.py`），然后审计了它。三个发现：

### 4.1 大部分分数来自共享的对照噪声

`Δ_pred = ŷ_treat − y_control` 与 `Δ_true = y_treat − y_control`
**共用同一个实测对照**。两边都含 `−y_control`，这一项与模型好坏无关，
却直接进相关系数。

判定性实验（`scripts/13_control_noise.py`）：**同一份预测**，只改对照参照
平均了几个孔——

| 平均的对照孔数 | 总分 | M2 |
|---|---:|---:|
| ≤1（平均 0.90 个/样本） | **0.5730** | 0.494 |
| ≤2（平均 1.73 个/样本） | 0.4771 | 0.404 |

**对照测得越准，分数越低。** 差 0.096，约 20%。

推论也成立：一个完全不含扰动信息的模型（只建板效应、预测 Δ≡0）
在 M2 上拿 0.370，而"用另一次重复实验的实测值"作预测只有 0.195。

### 4.2 M3 测不出化合物特异性

展开 μ_ctx（`m_ctx` = 该上下文下训练药物实测处理值的均值）：
`Δ_true − μ_ctx = y_treat − m_ctx`，`Δ_pred − μ_ctx = ŷ − m_ctx`。
M3 测的是两个「偏离 m_ctx 的方向」的夹角。三个后果：

- 完全不含化合物信息的模型得 **0.2125**；用另一次独立重复实验的实测值
  当预测只得 **0.092**。空模型是真实测量的 2.3 倍。
- 相关系数尺度不变，所以把预测幅度缩小 5 倍，M3 一点不变
  （λ=0…0.8 全都是 0.2125）——**M3 无法奖励幅度校准**。
- 预测恰好等于指标自己的参照（`m_ctx`，一个无偏的、条件在精确上下文上的
  合理估计量）时，残差是零向量，M3 = **0**。

M4 同性质、程度轻些：把未见菌株的预测移向 μ_drug 参照，M4 从 0.311 降到 0.286。

> 注：我们最初用「给未见化合物按系数 γ 补一个通用药物响应」来演示这一点，
> 但那个实验是混淆的——板效应项本身已经包含了平均处理水平，再加通用响应
> 属于重复计数。上面这版（`scripts/19_m3_clean.py`）没有这个问题。

### 4.3 分数对未公开的实现细节比对模型更敏感

同一份预测，在手册留白处取不同的合理解释：

| 留白处 | 总分范围（提交版预测） |
|---|---|
| 对照匹配到 DMSO / Water / 全部 / 按溶解性 | 0.481 – 0.564 |
| μ_ctx 的分组键：含板号 / 不含板号 | 0.481 – 0.530（M3 0.24 – 0.48） |
| M1 是否计入 R² | 0.481 – 0.495 |
| `y_control` 取实测值 / 取提交的预测值 | 0.399 – 0.481 |

**总跨度 0.399 – 0.564，约 0.165；而我们整个扰动模型的贡献是 +0.024。
口径歧义的影响是建模差异的 7 倍。**
所以我们报告的是一个区间，不是一个数；并且把这些问题整理给了组委会。

### 3.3 用满机器：把选择的方差压下去

前面所有取舍都是在 2–3 折上做的，而**折间标准差是 0.023**——
候选之间 0.001–0.002 的差距完全被它淹没。所以那些取舍其实没有被证实。

用 256 核把 (配置 × 折) 全并行，跑 6 个独立内层镜像，做**配对**比较
（配对后的标准误降到 0.0002–0.002，比非配对灵敏一个量级）：

| 相对当前配置 | Δ 总分 | ±sem | 判定 |
|---|---:|---:|---|
| **去掉残差 booster** | **−0.0104** | 0.0017 | ✅ booster 的收益是实的（约 6σ，两轮独立复现） |
| 板收缩用默认 1.0（不调） | −0.0029 | 0.0004 | ✅ 调它有用（约 7σ） |
| 板收缩 0.15 / 0.45 / 0.6 | −0.0005 / −0.0003 / −0.0007 | ~0.0004 | 最优区间很平，0.3 没问题 |
| plate×strain 收缩 1 / 6 | −0.0014 / +0.0005 | ~0.0004 | 2.0 与 6.0 无法区分 |
| booster 160 成分 | +0.0003 | 0.0001 | 名义显著但量级可忽略 |
| booster lr .015 / 1600 棵 | +0.0005 | 0.0002 | 同上，且训练时间翻倍 |
| 重测：低秩截断 / 条件-单元项 / 化合物×上下文项 / n_pass=10 | +0.0004 / −0.0007 / −0.0012 / −0.0062 | | ✅ 之前的否决全部复现 |

最后两行的 +0.0003 / +0.0005 **不采用**：我们前后在这套折上比较了约 30 个配置，
2–2.5σ 的结果正是多重比较该出现的量级，而且它们比 booster 的收益小 20 倍。

> 过程中发现自己脚本里的一个错误：第一轮把参照配置写成了空字典，
> 而空字典会回落到 `BATCH_FACTORS` 的默认 `lam_plate=1.0`，不是调过的 0.3——
> 参照行标错了。第二轮（`scripts/26b_focused_search.py`）显式写出参照的每个取值。

### 3.4 与官方口径基线的比较

手册说组委会提供「均值模型、随机森林、梯度提升」基线，且跨方向排名要
「相对基线归一化」——但基线一直没发布。我们自己实现了三个
（元数据特征 → log2 矩阵前 64 个主成分 → 重构，不做批次分解）：

| | 总分 | M1 | M2 | M3 | M4 |
|---|---:|---:|---:|---:|---:|
| 均值模型 | 0.240 | 0.459 | 0.185 | 0.035 | 0.216 |
| 随机森林 | 0.381 | 0.793 | 0.287 | 0.120 | 0.243 |
| 梯度提升 | 0.422 | 0.833 | 0.331 | 0.143 | 0.294 |
| 可加模型 | 0.471 | 0.868 | 0.399 | 0.220 | 0.309 |
| **可加 + 残差 booster** | **0.481** | 0.868 | 0.407 | 0.239 | 0.326 |

**相对最强的官方口径基线 +0.059，即 +14.1%。**

### 4.4 M2 与 M4 在未见菌株划分上方向相反

上面那条曲线显示：在未见菌株划分上，**任何让原始 FC 变好的改动都会让
M4 变差**，反之亦然。原因和 §4.2 是同一个——M4 减掉的 μ_drug 就是"该药物在
训练上下文里的平均 Δ"，而让 FC 变好的最有效办法恰恰是把预测推向那个平均值，
于是残差趋近于零。

后果：M2（25%）+ M4（20%）合计 45% 的权重，在这个最大的 OOD 划分（本地 1,547 行、
正式 1,534 行）上**部分互相抵消**，总分沿这条轴几乎是平的。
这不是模型的问题，是两个模块的参照选择造成的。

## 5. 化学先验：一个有说服力的负结果

开放知识榜的核心假设是"公开化学知识能帮上未见化合物的外推"。我们测了：

1. 57 个扰动物全部解析到 PubChem（CID + SMILES，请求 URL 逐条留档）；
2. Morgan 指纹（半径 2，2048 位）+ 人工整理的作用机制分类（逐条可审查）；
3. 效应向量本身**是可靠的**：分半信度中位数 0.55，37 个化合物里 35 个 > 0.5；
4. 但**留一化合物转移的相关系数 ≈ 0**（各种核、各种秩都试过）；
5. 控制数据来源后的成对检验：同机制 vs 不同机制，去衰减相关系数相差
   **+0.007，置换检验 p = 0.95**（456 对）；
   结构相似度与响应相似度的 Spearman ρ = **−0.016，p = 0.73**。

**结论：在 46 个训练化合物的规模上，公开化学知识对这个任务没有可测的帮助。**
不是效应测不准（测得很准），是化合物响应的主轴（PC1 占 49%）是一条
**非特异的通用胁迫轴**，而剩下的特异成分与化学结构无关。

这同时意味着：**封闭数据榜与开放知识榜在这份数据上大概率不可区分**。

## 6. 三路对抗审查（自查 → 修 → 迭代）

对自己的工作做了三条互不重叠的攻击。**四个真问题，全部已修**。

### 6.1 一路 · 统计打假

| 检查 | 结果 |
|---|---|
| 评测原语 vs scipy / sklearn | PCC 差 2e-16、R² 差 4e-16、AP 差 0 —— **通过** |
| 退化情形（常数行、有效点 < 3） | 正确返回 NaN 而不是 0 —— **通过** |
| **val 分数的置信区间** | ⚠️ **之前从没算过**。自助重采样：**±0.020**（95%） |
| **booster 的 +0.010 是真的吗** | 配对自助：**+0.0100，95% CI [+0.0089, +0.0114]，不含 0 → 真** |

**后果：单个 val 分数只精确到 ±0.02**，报到小数点后四位是假精度。
0.4811 与 0.4711 的差要靠**配对**比较才成立，不能从两个数直接读。
（自助均值 0.454 / 0.464 比点估计低约 0.017——重采样会重复行、
稀释蛋白轴相关，所以自助值只能用来估**宽度**，不能当**位置**。）

> ⚠️ **一处需要更正的说法**：前面文档写过「官方 val 镜像只评一次」。
> 这是不准确的——随着模型演进，val 已经被评过若干次（0.4065 → 0.4702 →
> 0.4711 → 0.4811）。准确的说法是：**所有超参与结构选择都在内层镜像上做，
> val 只用于报告，从未参与选择**。但它已不再是一个"未被看过"的集合，
> 报告时应按 ±0.02 的精度理解。

### 6.2 二路 · 评委视角

**发现的最大缺口：整个仓库没有一处检验模型是否学到了生物学**，
全是相关系数。补做了预注册的生物学检验（§7）。

### 6.3 三路 · 复现打假

| 问题 | 修复 |
|---|---|

## 7. 生物学检验：模型学到的是生物学还是批次？

预先写死 10 条教科书级的酿酒酵母响应（标记基因集与方向在看任何结果之前固定），
先看**实测数据**里有没有，再看**模型**有没有复现（`scripts/29_biology_check.py`）：

| 化合物 | 标记集 | 预期 | 模型可见? | 实测 | 模型 | 结论 |
|---|---|---|---|---:|---:|---|
| Rapamycin | 核糖体蛋白 | ↓ | 是 | **−0.159** (p=1e-29) | **−0.165** | ✅ |
| Tunicamycin | UPR / ER | ↑ | 是 | **+0.458** (p=7e-11) | **+0.375** | ✅ |
| NaCl | 渗透胁迫 | ↑ | 是 | **+0.503** (p=3e-09) | **+0.434** | ✅ |
| Cisplatin | RNR / DNA 损伤 | ↑ | 是 | **+0.482** (p=6e-07) | **+0.392** | ✅ |
| Sorbitol | 渗透胁迫 | ↑ | 是 | **+0.347** (p=4e-08) | **+0.260** | ✅ |
| Parthenolide | 氧化胁迫 | ↑ | 是 | **+0.268** (p=2e-04) | **+0.178** | ✅ |
| **Hydroxyurea** | **RNR / DNA 损伤** | ↑ | **否（留出）** | **+1.309** (p=3e-14) | **−0.008** | ❌ |
| **Sulfometuron** | **氨基酸合成** | ↑ | **否（留出）** | **+0.131** (p=1e-05) | **−0.023** | ❌ |
| Rapamycin | 热激 | ↑ | 是 | +0.137 (p=0.055) | −0.057 | 数据本身不显著 |
| Geldanamycin | 热激 | ↑ | 是 | −0.031 (n.s.) | −0.091 | 数据里没有这个效应 |

**10 条里 8 条在实测数据中成立；这 8 条中：**

- **模型能看到的化合物：6 / 6 全部复现**
- **被留出的化合物：0 / 2**

这是一个干净的双分离。它用生物学而不是相关系数说清了两件事：
**(1) 模型确实学到了扰动生物学**，不是只会建批次；
**(2) 未见化合物的外推确实做不到**——羟基脲的 RNR 诱导 **+1.31 log2 是整个
面板里最大的效应**，模型给出 −0.008。

这也把 §5 的化学负结果落到了实处：如果化学先验真的能迁移，
羟基脲这种机制极其明确的化合物本该是最容易迁移的一个。

## 9. 诚实性设计

- 泄漏的测试真值物理隔离，加载器对 `test` 直接抛异常；
- 超参在**内层镜像**（从训练行再切一次，留出 CEK / CGD / DHY210 三种菌株
  各一折）上选，官方 val 镜像只评一次；
- 每个模块都同时报告**下限**（无扰动信息的模型）和**上限**
  （用真值 Δ 的 oracle、以及重复实验的复现上限），
  单独一个分数没有意义；
- 所有随机种子固定，`results/` 下每个数字都有对应脚本。
