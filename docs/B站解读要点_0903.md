## 官方"建议建模路线"与我们的对应实验（报告可直接引用）
- `strain → genome → embedding`（1011 计划；DHY210 用 S288c/SGD）→ 我们做了 PAV/CNV/移码诊断（63–65）与同批分离株实测蛋白质组（87）：机制真但只覆盖 b 方差 ~10%，+0.0003/+0.0001，未采纳
- `chemical → SMILES → embedding` → 化学相似度迁移为负（05）；专家机制类供体也为负（90）
- "decoder 里引入仪器变量" → 加性层 instrument 项（排在 plate 之前，+0.0017）+ booster 特征
- 口播："算法是第二优先级，数据是第一" / "模型应能告诉我们该采什么数据" → 报告"后续研究路径"可呼应（主动学习）
